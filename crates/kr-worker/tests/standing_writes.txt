# The writes inside the standing function.
#
# Held in both directions by the scan of the same name. The scope rows name the four pieces of the
# function, the checks they call directly, the pure readers of the clocks and the gate, and the
# broker's checks and the three wrappers of a lock that the pure readers call. The scan reads those
# bodies and, besides, the helpers that they reach by a name that this crate declares once, and the
# ones those reach in turn (not the callee of a name that the roster counts). In every body that is
# read, scoped or followed, a call to a name that several functions declare has to be a counted
# name, an `outside` one, allowed for that body (a method of the standard library or of another
# crate) or given the file of its definition by a `calls` row (a function of this crate); a scope
# row exempts no call.
#
# scope <file> <function>
# site <file> <function> <callee> <how many calls>
# outside <file> <function>
# allow <file> <function> <name> ...
# calls <file> <function> <name> <file of the definition>
# caller <callee> <file> <function> <count>
# only <callee> <file> <function> <count>
# held <file> <function> <callee> <guards>
# supplies <file> <function> <callee> <position> <text>
