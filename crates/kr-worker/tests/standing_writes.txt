# function, the checks they call directly, the pure readers of the clocks and the gate, and the
# broker's checks, and the helpers that those checks call and that this list reads. A function of
# this crate that a scoped body calls has to be a scoped one, an `outside` one or an `allow` name,
# and a helper that is not read is not followed: what it calls is not seen.
#

# site <file> <function> <callee> <how many calls>
# outside <file> <function>
# allow <name> ...
# caller <callee> <file> <function> <count>
# only <callee> <file> <function> <count>
# held <file> <function> <callee> <guards>

# first admission's. The note of a journal that failed is the first admission's own, made by its
# wrapper from what the limits hand back, and stands outside the scope.

# local `Option`, not a state that others read.
