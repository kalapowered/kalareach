# The takes of a lock inside the standing function.
#
# Held in both directions by the scan of the same name. The scope is the four pieces of the
# function, the checks they call directly, the pure readers of the clocks and the gate, and the
# broker's checks, the three wrappers of a lock that the pure readers call, and the helpers that
# those reach by a name that this crate declares once, which the scan reads and follows as well. A
# name that several functions declare has to be a scoped function, an `outside` one or allowed for
# the one body that calls it.
#
# scope <file> <function>
# site <file> <function> <callee> <how many calls>
# outside <file> <function>
# allow <file> <function> <name> ...
# caller <callee> <file> <function> <count>
# only <callee> <file> <function> <count>
# held <file> <function> <callee> <guards>
# supplies <file> <function> <callee> <position> <text>
