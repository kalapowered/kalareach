# The calls of the four ways to append output and of every wait for the write that is in flight, and
# the history's readers. Held in both directions by owed_write_waits.rs; what the scan cannot see is
# said in its header.
#
# site <file> <function> <callee> <how many calls>
# reader <method> via <standing | the method it answers through>
# exempt <method> <why a completed discard leaves it as it is>

# The one appender: the pump calls the session's entry point, which calls the history's, which waits
# for its own earlier write at its head. The history's `append` calls the same entry point and has
# no shipped caller outside it; `Session::ingest_output` has none.
site crates/kr-worker/src/runtime.rs start_and_say_if_the_shell_ended ingest_output_deferring_the_spool 1
site crates/kr-worker/src/session.rs ingest_output ingest_output_deferring_the_spool 1
site crates/kr-worker/src/session.rs ingest_output_deferring_the_spool append_deferred 1
site crates/kr-worker/src/history.rs append append_deferred 1
site crates/kr-worker/src/history.rs append_deferred wait_for_owed_write 1

# The waits for the write in flight. `wait_idle` has one caller, the appender's own wait. The test
# helpers wait with the session held and are compiled only with the testing feature. The privacy
# call's wait is bounded and holds no lock of the session's, which this scan does not see.
site crates/kr-worker/src/history.rs wait_for_owed_write wait_idle 1
site crates/kr-worker/src/history.rs wait_for_the_spool_write wait_for_owed_write 1
site crates/kr-worker/src/session.rs wait_for_the_spool_write wait_for_the_spool_write 1
site crates/kr-worker/src/runtime.rs wait_for_the_spool_write wait_for_the_spool_write 1
site crates/kr-worker/src/history.rs wait_idle_for wait_idle_for 1
site crates/kr-worker/src/service.rs take_privacy wait_idle_for 1
