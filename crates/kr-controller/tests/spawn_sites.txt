# Every place in the daemon's process that starts a task, a blocking pass or a thread, one row each.
# The daemon's process is the controller crate and every local crate it links; the scan in
# spawn_sites.rs reads their source and fails when a start has no row or a row has no start.
#
# file | function | form | callee | count | class | task | note
#
# A row is the file, the function, the form of the start (the start function as written; a method
# is written with a leading dot) and the callee (what the start runs: a function, or the first
# call of an async block or a closure that does work), and stands for `count` starts that share all four.
# `task` is the number (1 to 36) of the long-lived task of the daemon that the row belongs to, or `-`.
# Number 36 is the family of threads, tasks and process launches that a request starts and does not bound.
#
# Classes, and what the case checks of each:
#   supervised-later  a task that lives as long as the daemon, or as long as something that no request
#                     bounds, which a task supervisor must take; its note says how long it lives (a
#                     person's read)
#   request           ends with the request, connection, session or work that started it; never a start
#                     whose end the request does not bound. Its note begins with its bound,
#                     `bound(form at path:line); the bound in words`, and the case checks that the form
#                     is one of the five below and that the place is a line of a file of the tree that
#                     holds what the form names. A row for which no place holds is not `request`.
#   joined            its handle is awaited. A start that is awaited where it stands must be this class,
#                     and a row of this class whose start is not awaited where it stands has a marker
#                     `join(function on name)` in its note, which the case checks against the source
#   other_crate       a task of a linked crate; its note says whose program runs it (a person's read)
#   test              compiled in only by a test build or the testing feature; every such start is
#                     this class, and every row of this class has such a start
#
# The five forms of a `request` row's bound, with the words that the line of its place must hold (the
# case reads the line's words, not a parse: it does not see that the `.await` is the task's handle's,
# that the set is the one the task goes into, that the `Drop` aborts the task, or that the receive is in
# every wait of the task, which a person's read of the code decides; a comment's or a string's words
# do not count):
#   await             the handle is awaited by a future that no deadline, branch or drop can leave;
#                     the place is the await's line (`.await`)
#   owned-set         the task goes into a set that its owner aborts when it is dropped; the place is the
#                     set's declaration (`JoinSet`, not a `use`)
#   guard             a guard whose drop aborts the task; the place is the guard's `Drop`
#                     (`impl .. Drop for ..`)
#   connection-guard  the connection's own guard; the place is the guard's `Drop`, of a type with
#                     `Connection` in its name
#   channel           the owner's end of a channel that the task reads in every wait, so that the owner's
#                     drop ends the task at its next poll; the place is the task's read of that end (a
#                     method call `recv`, `poll_recv`, `recv_many`, `try_recv`, `blocking_recv`, `closed`
#                     or `changed`)
#
# A helper line, `helper | name | scope | note`, names a function that starts a task running one of
# its own parameters of a closure or a future type: each call of that name in a file under scope is a
# start, keyed by the argument at that parameter's place.
#
