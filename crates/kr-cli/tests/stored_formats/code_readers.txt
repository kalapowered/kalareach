# The roster of every reader of a kept protocol error code. The scan in ../code_readers.rs holds it against the product source.
#
# A store keeps an error code as its wire word, and a code that the protocol gains raises no store's version. In exchange every reader of a
# kept code has one declared reading of a word that it does not know: never absent, never a success, never a new claim or a repeated effect,
# never a definite refusal under another code; the outcome is unknown, with the record kept. Each row below names one reader (a function that
# turns text into a code, or the types that hold a code and derive Deserialize), the reading, and the case that holds the reading.
#
# Row: kind | class | place | file | names | sites | how the code is read | the reading for a word this build lacks | case
#   kind    site (names a function; sites is how many calls of it) or type (names types of the file, comma separated; sites is -)
#   class   stored (a store keeps the bytes and the row names its cases as crate::target::name, comma separated, lib for a unit case in the crate's source;
#           a type row's place names each store of the table that keeps the type, as the table spells the store), wire (a frame, reply or
#           fixture decoded from a peer, a caller or a test input, and kept in no store), not-code (a call or a type that the scan sees and
#           that holds or reads no error code; a type row says which shared name made it a holder)
#
# Why the wire rows hold: the scan reads the stored-formats table and fails when a store keeps a type that holds a code and no stored row names
# that type for that store, so a type kept by a store is never classed wire or not-code. Of the types below, the table's stores keep
# ProtocolError (the catalogue's receipts), KeyDeclaration (the registry) and the merge plan's types. A wire row is the author's claim about
# the reader's own code: that it decodes a frame or a reply and keeps it in no store. The scan does not prove that.
#
# What the scan cannot see (it reads product text only): a code that reaches a store as text through another function or a string match; a
# hand-written decoder; a call made by a macro; a type alias or a renamed import of ErrorCode; Rust outside crates/*/src and apps/**/src;
# a new decode (serde_json::from_str::<ProtocolError>, a canonical CBOR decode) of a type that already has a row, which adds no parse site.
# It follows a holder by type NAME, so a name that two crates share counts for both: more rows, never fewer.
#
# Places 1 to 9 of the stored places are marked below. The worker's journals (place 9) keep the archive's own rule and are outside the
# stored-formats lock.
